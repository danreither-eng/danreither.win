A practical learning roadmap

Build from literacy to applied work, then specialize.

  1. Learn AI fundamentals, limitations, and how to verify outputs.
  2. Practice everyday research and productivity with more than one assistant.
  3. Learn embeddings, retrieval-augmented generation, APIs, and evaluation.
  4. Study governance and security with NIST AI RMF, OWASP, and MITRE ATLAS.
  5. Choose an engineering, governance, security, or product specialty and demonstrate it through a non-sensitive portfolio.

AI glossary

AI: Systems performing tasks associated with language, prediction, perception, or decision-making. Machine learning: Methods that learn patterns from data. Deep learning: Machine learning using multi-layer neural networks. Generative AI: Models that produce content such as text, images, audio, or code. LLM: A large language model processes and generates language. Multimodal: Working across combinations of text, images, audio, or other data. Prompt engineering: Designing instructions and context for a task. RAG: Retrieval-augmented generation adds retrieved information to a model’s context. Embedding: A numerical representation used to compare data. Agent: A system that can use tools or execute steps toward a goal. MCP: Model Context Protocol, a way to connect AI applications to tools and data. Fine-tuning: Additional training that adapts a model for a task or domain. Inference: Running a trained model to produce output. Evaluation: Measuring performance, reliability, and safety against defined tasks. Guardrails: Controls intended to reduce unwanted behavior. AI red teaming: Structured adversarial testing of AI systems. MLOps / LLMOps: Practices for deploying, monitoring, and maintaining ML or LLM systems.

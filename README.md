# CyberPro Hub

A clean, modern static website for seasoned cybersecurity practitioners.

Curated sections:
- Renowned news sources
- Threat intel feeds & newsletters
- Expert voices
- Best podcasts (Pocket Casts friendly)
- High-signal X/Twitter accounts
- Top Reddit communities
- Essential tools & references

## Deploy to Cloudflare Pages (Free)

1. Create a new project in the [Cloudflare Dashboard](https://dash.cloudflare.com/) → Pages.
2. Connect a Git repo **or** use direct upload.
3. Upload the contents of this folder (`index.html`, `styles.css`, `script.js`).
4. Set the build command to empty / none (it’s already static).
5. Publish. Your site will be live on `*.pages.dev` (and you can add a custom domain).

No build step required. Works with Cloudflare’s free tier.

## Customize

- Edit `index.html` to add/remove links or change copy.
- Adjust colors and spacing in `styles.css` (CSS variables at the top).
- Theme toggle (dark/light) is built-in and remembers preference.

Built as a single-page resource hub — no trackers, no backend.
